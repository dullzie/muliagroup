# MULIA GROUP — Corporate Profile

Static company profile website for MULIA GROUP.

## Deploy to Vercel (Free)

1. Create a new GitHub repository, for example `muliagroup`.
2. Upload these files to the repository root.
3. Make sure `index.html` is at the root level.
4. Import the repository into Vercel.
5. Deploy with the default settings for a static site.
6. Set the Vercel project name to `muliagroup` if the name is available.

Target URL:

`https://muliagroup.vercel.app/`

## WhatsApp / Social Preview

The page is configured with Open Graph metadata and expects:

`/cover.jpg`

Recommended cover size: **1200 × 630 px**, JPG, publicly accessible.

Also place:

`/favicon.png`

in the repository root.

## Important

If Vercel assigns a different URL because `muliagroup.vercel.app` is unavailable, replace the old URL in `index.html`, `robots.txt`, and `sitemap.xml` with the actual Vercel URL.
